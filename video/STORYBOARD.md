# 学習装置 ローンチ動画 ストーリーボード（Issue #193）

- 1920×1080 / 30fps / 900 フレーム（30 秒）
- 音楽は 120 BPM。1 拍 = 15 フレーム、1 小節 = 60 フレーム（2 秒）。場面の切り替えは小節頭に置く
- 音は `scripts/make-audio.ts` が合成する（外部素材なし、ライセンスの心配なし）

| #   | 時間   | 小節  | 画                                                                                                                                                  | テロップ                                   | 音                                                       |
| --- | ------ | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | -------------------------------------------------------- |

## 作り方

```bash
cd video
npm install
npm run render   # 音を合成してから out/launch.mp4 を書き出す
npm run studio   # プレビュー
```

拍や効果音の位置を変えるときは `src/timeline.ts` だけを直す。映像と音の両方がここを読む。
