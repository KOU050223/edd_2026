# 学習装置 ローンチ動画 ストーリーボード（Issue #193）

- 1920×1080 / 30fps / 2280 フレーム（76 秒、38 小節）
- 音楽は 120 BPM。1 拍 = 15 フレーム、1 小節 = 60 フレーム（2 秒）。場面の切り替えは小節頭に置く
- BGM と効果音は `scripts/make-audio.ts` が合成する（外部素材なし）
- ナレーションは Gemini TTS（`gemini-3.8-flash-tts`、声は Charon）。`scripts/make-voice.ts` が生成し、
  `public/voice/` に保存する。読み上げの間は BGM を約 12dB 下げる
- 尺はナレーションが決める。62 秒版に読み上げを載せると合計が約 80 秒になり収まらなかったので、
  原稿を言い切りの形に縮め（合計約 60 秒）、場面の尺を読み上げに合わせて延ばした
- キーを押す瞬間やマップの色を光らせる瞬間は、生成した音声の無音区間を測り、
  その言葉を読む位置に合わせてある。原稿を作り直したら測り直すこと

## 作り方

```bash
cd video
npm install
GEMINI_API_KEY=... npm run voice   # ナレーションを生成（原稿を変えた行だけ API を呼ぶ）
npm run render   # BGM・効果音・ナレーションをミックスして out/launch.mp4 を書き出す
npm run studio   # プレビュー
```

拍や効果音の位置を変えるときは `src/timeline.ts` だけを直す。映像と音の両方がここを読む。
