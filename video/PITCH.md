# 発表の台本（デモ抜き 3 分）と、裏で流す映像

プレゼン 5 分のうち、デモを除いた 3 分ぶん。構成は「概要 1 分 ＋ 工夫した点 2 分」。
ポスターセッション以降に足したこと（AI の履歴からの地図・リポジトリからの地図・共有）を中心にする。

- 映像: `out/pitch.mp4`（1920×1080 / 30fps / 3:00、音なし）。`npm run render:pitch` で書き出す
- 映像は台本の段落と同じ秒で切り替わる。**左の `[0:00]` が映像の時刻**。話し始めと再生を同時にする
- AI の履歴からの取り込みは、デモを映像の中で見せながら話す（実機の操作を省いて時間を縮める）
- 読む速さは 1 秒 5〜6 文字を目安にしている。各段落の（ ）は映像がその段落に割いている秒数。
  詰まっている段落は、直後の短い段落（[1:34]・[2:21] など）へ少しはみ出しても映像とずれない
- 映像の割り付けは `src/pitch/timeline.ts`。台本を直して尺が変わったら、そこの秒数も直す

## 概要（0:00〜1:00）

**[0:00] 導入** 映像: エラーの波線と「調べに行く」カード（8 秒）

> プログラミングの「わからない」は、手が止まった瞬間にやってきます。
> 調べに行くたび、集中は切れてしまう。

**[0:08] VS Code** 映像: コードを選んで ⌘⇧J → ヒントと次の一手（18 秒）

> 学習装置は、その場で聞ける学習の相棒です。
> VS Code では、コードを選んでコマンド・シフト・J。
> 選んだコードとエラーが、そのまま質問になります。
> 返ってくるのは答えではなく、ヒントと「次に試す一手」です。

**[0:26] Desktop** 映像: ブラウザで ⌘⇧K → 常駐アプリ（14 秒）

> エディタの外でも、ブラウザでもターミナルでも、
> 文字を選んでコマンド・シフト・K。常駐アプリがそのまま拾います。

**[0:40] 学習マップ** 映像: ノードが灯る → 色の意味 → 次の候補（14 秒）

> 聞いたやりとりは自動で記録され、理解した概念が地図に記されていきます。
> 緑が確認済み、オレンジが学習中、青がいまの現在地です。

**[0:54] つなぎ** 映像: 「ポスターセッションのあと、地図の作り方を広げました」（6 秒）

> ポスターセッションのあと、この地図の作り方を 2 つ広げました。

## 工夫① 普段使っている AI の履歴から地図を作る（1:00〜2:00）

映像はデモ。Desktop で取り込み → Web のマップに印が付くまでを 1 分で見せる。
右の欄に要点が 1 つずつ出るので、それを読み上げる気持ちで話す。

**[1:00] 困りごと**（8 秒）

> ひとつ目は、普段使っている AI の履歴から地図を作る機能です。
> 使い始めの真っ白な地図を、これまでの学習で埋めます。

**[1:08] 履歴を見つける** 映像: 「履歴から地図を作る」を押す → 見つかった履歴（11 秒）

> ボタンを押すと、この PC にある Claude Code、Codex、VS Code の履歴を自動で見つけます。
> ChatGPT や Claude のエクスポートファイルも選べます。

**[1:19] 読み解く（工夫の中心）** 映像: 進み具合のバー（15 秒）

> 工夫したのはプライバシーです。本文は端末の中で処理し、メールアドレスやトークンは先に取り除きます。
> 分類はまず手元のルールで、足りない分だけ AI に回します。
> サーバーへ送るのは、どの概念に触れたかだけです。

**[1:34] 確認して適用** 映像: 見つかった概念の一覧 → 1 つ外す → 地図に適用（7 秒）

> 見つかった概念は、送る前に確認して外せます。

**[1:41] 「触れた」と「理解した」を分ける** 映像: Web のマップに「履歴あり」の印（19 秒）

> 適用すると、触れた概念に「履歴あり」の印が付きます。
> 大事にしたのは、「触れた」と「理解した」を混ぜないこと。
> 履歴だけでは理解度は上げず、確認問題に正解して、はじめて緑になります。

## 補足（話す人向け）

- 映像の数字（会話 527 件、観測の件数など）は説明用の値。取り込みの画面は Desktop の実装
  （`apps/desktop/src/renderer/index.html` の `#import`、`history.js`）の文言と手順を再現したもの。
  画面の右下にもその旨を出している
- リポジトリからの地図（Issue #249）は開発中。画面はまだ無く、Issue の設計とスパイクの結果から描いた。
  トークン数（8,000〜17,000、約 $0.01）はスパイクの実測（Issue #249 のコメント、2026-10-10）
- 時間が押したら削る順: [2:40] の 2 文目 → [1:08] の 2 文目 → [1:41] の 2 文目
